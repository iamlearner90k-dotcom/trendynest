# 🛍️ TrendyNest - Full-Stack E-Commerce Platform

A fully functional, responsive, and modern dynamic e-commerce web application designed for a seamless online shopping experience.

## 🚀 Live Demo
- **Frontend (Vercel):** [https://trendynest-s2nx.vercel.app](https://trendynest-s2nx.vercel.app)
- **Backend (Render):** [https://trendynest-hfw9.onrender.com](https://trendynest-hfw9.onrender.com)

---

## ✨ Key Features

- **📱 Fully Responsive UI:** Optimized layout for seamless mobile and desktop viewports.
- **🛒 Dynamic Product Catalog & Cart:** Real-time cart management using local storage and interactive controls.
- **🚚 Live Order Tracking:** Instant status updates using custom order IDs.
- **💳 Local Payment Integration:** Configured with bKash dynamic payment workflow.
- **📄 Instant Receipt Generator:** PDF/Downloadable client receipt generation after successful checkout.
- **⭐ Product Reviews & Ratings:** Interactive review display sections for products.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Grid & Flexbox), Modern Vanilla JavaScript (ES6+)
- **Backend:** Node.js, Express.js API Gateway
- **Deployment:** Vercel (Frontend), Render (Backend Continuous Deployment)
- **Version Control:** Git & GitHub Workflow
